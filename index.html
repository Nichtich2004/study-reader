Where do I get a key?
  • OpenAI — sign in at platform.openai.com/api-keys, click Create new secret key, copy it (starts with sk-). Add a few dollars of credit under Billing. Base URL https://api.openai.com/v1, model gpt-4o-mini.
  • Groq (free tier) — console.groq.com/keys. Base URL https://api.groq.com/openai/v1, model e.g. llama-3.3-70b-versatile.
  • OpenRouter — openrouter.ai/keys. Base URL https://openrouter.ai/api/v1, model e.g. openai/gpt-4o-mini.

Stored in this browser's localStorage only. It is sent only to the API base URL above. Never share or commit your key.
